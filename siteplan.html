Project Overview

The Explore Eswatini website is a portfolio project built using valid HTML, responsive CSS, and JavaScript-driven interactivity.

It supports trip planning, destination discovery, and a references page for cited sources.

Site Structure

  • index.html — Home page with hero image, introductory content, and navigation links.
  • temples.html — Destination page with filter buttons and dynamic travel cards generated by JavaScript.
  • form.html — Trip planning form with package selection, traveler details, interests, and email validation.
  • review.html — Itinerary summary page that reads submitted form values from the URL and shows the total request count.
  • references.html — Reference page linked from every footer with citations for travel information and image assets.

Target Audience

Travelers who want easy-to-read Eswatini tourism information, including families, solo visitors, and small tour groups.

The site focuses on accessibility, usability, and simple navigation across mobile and desktop devices.

Design and Accessibility

  • Mobile-first responsive design with clean cards and readable spacing.
  • High contrast colors, clear headings, and consistent typography.
  • Lazy-loaded images with alt text for better performance and accessibility.
  • Semantic HTML sections and consistent footer navigation on all pages.

JavaScript Features

  • Dynamic card rendering using arrays and objects in scripts/temples.js.
  • Filter buttons update the DOM and store the selected filter in localStorage.
  • The trip planning form uses JS to populate options, validate input, and save request count.
  • The summary page reads URL parameters and displays the itinerary details.
  • The site plan page itself uses JS for interactive section buttons and saved selection state.
