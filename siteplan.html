Explore Eswatini - Site Plan

A tourism website designed to help users explore destinations and plan trips.

Project Overview

This website helps travelers explore destinations in Eswatini and plan their trips بسهولة. Users can browse locations, filter destinations, and submit trip requests through a form.

Site Structure

  • index.html – Home page introducing Eswatini and the website.
  • temples.html – Displays destinations with filter buttons.
  • form.html – Trip planning form with user input fields.
  • review.html – Displays submitted trip details.
  • references.html – Lists sources used.

Target Audience

Travelers interested in visiting Eswatini, including tourists, families, and solo travelers. The site is designed to be simple, clear, and accessible.

Design and Accessibility

  • Responsive design for mobile and desktop devices
  • Readable fonts and high contrast colors
  • Semantic HTML structure
  • Images include alt text and lazy loading

JavaScript Features

  • Dynamic destination cards using arrays and objects
  • Filter buttons that update displayed content
  • Form validation and submission handling
  • Review page reads URL parameters
  • localStorage used to track number of requests
